# GDP推移シミュレーター（政府支出・乗数効果モデル）

マクロ経済学における基本的なGDP決定理論（乗数効果）を取り入れた、シンプルな経済成長推移シミュレーションWebアプリケーションです。PHPベースで動作し、ブラウザ上で直感的にパラメータを変更して経済予測を試すことができます。

## 🚀 機能特徴

- **民間の自然成長シミュレーション:** 初期GDPに対する純粋な民間経済の自律的成長を計算。
- **政府支出（財政政策）の動的反映:** 毎年の追加政府投資がGDPに与えるインパクトをシミュレート。
- **乗数効果の可視化:** 投資された資金が経済循環を通じて何倍のGDP押し上げ効果を生むかを動的に計算（$政府支出 \times 乗数$）。
- **レスポンシブなUI:** CSS Gridを使用した直感的な入力フォームと、結果を一目で把握できる動的な集計テーブル。

## 📊 経済計算ロジック

本プログラムは以下のマクロ経済モデルをベースに毎年の推移を計算しています。

$$今年のGDP = \left(前年のGDP \times (1 + \frac{民間の自然成長率}{100})\right) + （毎年の政府支出 \times 乗数倍率）$$

- **乗数（Multiplier）とは:** 政府支出が新たな所得と消費を生み出し、最初の支出額以上に経済を拡大させる連鎖効果の比率です。

## 🛠️ 動作環境

- PHP 7.4 / 8.0 / 8.1 / 8.2 / 8.3 +
- Webブラウザ（Chrome, Edge, Safari, Firefox等）
- *※外部データベースやJavaScriptライブラリへの依存はありません。単一ファイルで動作します。*

1. **ファイルの配置**
   リポジトリ内の `gdp_sim_advanced.php` を、ローカルの開発環境（XAMPP, MAMP, Docker等）またはWEBサーバーの公開ディレクトリ（`htdocs` や `www`）に配置します。

2. **ビルトインサーバーでのクイック起動**
   PHPがインストールされている環境であれば、ターミナルでファイルのあるディレクトリに移動し、以下のコマンドで簡易サーバーを起動できます。

💡 シミュレーションの活用例（実験アプローチ）
緊縮財政 vs 積極財政の比較
「毎年の追加政府支出」を 0 に設定した場合（純粋な民間経済のみ）と、数値を付与した場合で、10年〜20年後の総GDPおよび成長曲線にどのような格差が生まれるかを検証できます。

投資の「質」の検証
乗数を 1.0（単発の消費的支出）にした場合と、1.5 以上（インフラや技術投資など、民間の生産性を誘発するスマートな投資）にした場合で、財政出動の効率性がどう変わるかを視覚的に確認できます。
